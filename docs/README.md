## 公開サイトの再配布支援

- `/redistribution-support`：手元にファイルがある人向け。ファイルを添付して権利者への問い合わせを相談できます。
- `/publisher-support`：配布元・権利者向け。配布先探しや配布対応の代行を相談できます。
- 添付ファイルは最大100 MiB。管理画面の申請詳細から担当者が取得できます。申請が却下・終了になると添付ファイルを削除します。
- 許諾確認前に公開・再配布を行わない運用です。
