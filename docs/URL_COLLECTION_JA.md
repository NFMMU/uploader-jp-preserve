# URL自動収集（管理者向け）

## できること

管理画面の「URL自動収集」から、DuckDuckGoで uploader.jp / getuploader.com のリンクが掲載されていそうな公開Webページを自動検索できます。検索語を空欄にすると、MMDモデル・モーション・エフェクト・ステージ・配布の5種類を検索します。必要に応じて検索語を最大5件指定できます。各検索語から最大2件、合計最大10件の公開HTTPSページを巡回元として選びます。DuckDuckGoの公開HTML検索を使うため、検索APIキーは不要です。

巡回元の同一ホスト内を浅く巡回し、HTML内の `uploader.jp` / `getuploader.com` の個別ダウンロードリンクを抽出します。1回の実行あたり、合計最大20ページ、候補URLは最大100件、リンク先の確認リクエストは重複を除いて最大20件です。確認上限に達した場合は残りの候補をスキップし、結果を「上限に到達」と表示します。検索結果はDuckDuckGoのインデックスやサイトの応答に依存し、必ずしもすべてのリンクを発見できるわけではありません。

検出したリンク先には登録前にRange付きリクエストを送り、HTTP 2xx以外を返すURLは候補から除外します。この確認は応答本文を読み込まず、ファイル本体の保存・配布は行いません。

確認を通過した新規URLは「申請・保全レビュー」に `pending` の保全リクエストとして登録されます。自動探索だけでファイル本体のダウンロード、保存ノードへの配布、一般公開を開始しません。内容・権利条件を確認し、担当者が申請レビューから取得を開始してください。

## 安全・アクセス制限

- 開始URLは公開された HTTPS ページに限ります。
- ページ巡回は開始URLと同一ホストに限定し、深さは最大2リンク、全体で最大20ページです。
- 1ページ最大8 MiB、HTTPタイムアウト付きです。巡回間には短い間隔を空けます。
- DNS解決先を検査し、ループバック、プライベート、リンクローカル、予約済みIPアドレスなど内部ネットワークへの接続を拒否します。リダイレクト先もHTTPSかつ公開IPでなければ拒否します。
- ログイン、パスワード、CAPTCHA、アクセス制限を自動で回避しません。
- 利用規約、robots.txt、サイト運営者の意向を尊重してください。アクセス拒否や削除依頼があったサイトは収集対象から外してください。
- DuckDuckGo検索を利用しますが、検索エンジンのインデックスにないページや検索結果に表示されないリンクは見つかりません。巡回対象ページの規約・robots.txt等の確認は運営者の責任です。

## 重複排除

- URLのホスト名を小文字化し、`#fragment` と既定の `:443` を取り除いたURLを重複判定キーにします。
- クエリ文字列はダウンロード用トークン等に使われる可能性があるため保持します。
- 既に収集レジストリにあるURL、保全リクエストにあるURL、またはファイル一覧に登録済みのURLは新しい申請を作成せず、重複として破棄します。
- 手動の保全リクエストと自動収集の両方が同じURLレジストリを利用します。DBの一意制約により、同時実行時の重複登録も抑止します。
- パスやクエリの意味がある場合があるため、パス末尾のスラッシュや異なるクエリ文字列を機械的に同一視しません。

## データベース更新

新規環境では通常どおり Atlas のマイグレーションを適用してください。既存環境では `atlas/migrations/20261024060000_url_collection_dedup.sql` を適用してから新しい API/Web コンテナを起動してください。
