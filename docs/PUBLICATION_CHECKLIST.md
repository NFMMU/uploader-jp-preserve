# GitHub 公開前チェックリスト

公開前にリポジトリ管理者が確認してください。

- [x] ソースコード用の MIT `LICENSE` を追加する（第三者コンテンツには適用しない）。
- [ ] 利用規約・プライバシー・ポリシー・免責事項のドラフトを実運用に合わせて確認し、必要に応じて法律専門家のレビューを受ける。
- [ ] uploader.jp 保全プロジェクトの運営方針、参加ノード規約、著作権侵害申告・公開停止・削除の対応手順を確認する。
- [ ] 公開リポジトリに `.env`、API トークン、登録トークン、秘密鍵、個人情報、実データが含まれていないことを確認する。
- [ ] `deploy/participant-node/.env.example` と `.env.example` に実環境の秘密情報が入っていないことを確認する。
- [ ] `docker compose config --quiet`、Go テスト、Web ビルドを実行し、結果を確認する。
- [ ] CI が成功することを確認する。
- [ ] 初期管理者パスワード、JWT secret、ノード登録トークンの本番設定とローテーション方法を決める。
- [ ] 本番環境の TLS、バックアップ／復元、監視、レート制限、インシデント対応を確認する。
- [ ] 問い合わせ先 `uploaderjp-archive@udonya.moe` が公開窓口として利用可能であることを確認する。
- [ ] 公開前に、依存関係のバージョン固定と `web/package-lock.json` の生成・コミットを検討する。
