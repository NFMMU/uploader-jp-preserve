# 管理者からのお知らせ

このディレクトリ内の Markdown ファイルが、管理画面の「管理者からのお知らせ」に表示されます。

## 追加方法

1. `YYYY-MM-DD-short-title.md` の形式で Markdown ファイルを追加します。
2. ファイル先頭に YAML 形式のメタデータを記載します。
3. ブランチを作成し、Pull Request でレビューしてからマージします。

```yaml
---
title: "お知らせのタイトル"
date: "2026-11-17"
category: "メンテナンス"
pinned: false
---
```

- `title`: 一覧に表示するタイトル
- `date`: 公開日（`YYYY-MM-DD`）
- `category`: カテゴリ（例：重要、メンテナンス、更新情報）
- `pinned`: `true` にすると日付順より優先して上部に固定

本文は通常の Markdown で記述できます。HTML は使用せず、リンク・見出し・リスト・引用などを利用してください。
