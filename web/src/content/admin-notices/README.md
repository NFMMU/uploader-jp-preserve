# お知らせコンテンツ

このディレクトリの Markdown ファイルが、一般ユーザー向けのお知らせとして公開されます。

## 記事の追加

1. `YYYY-MM-DD-short-title.md` の形式で Markdown ファイルを追加します。
2. YAML Front Matter に記事情報を記述します。
3. Pull Request でレビューしてからマージします。

```yaml
---
title: "お知らせのタイトル"
date: "2026-11-17"
updated: "2026-11-18"
summary: "一覧に表示する短い概要。省略すると本文から自動生成されます。"
tags:
  - 重要
  - メンテナンス
pinned: false
published: true
---
```

### メタデータ

- `title`: 記事タイトル。省略時は本文先頭の H1、またはファイル名を使用します。
- `date`: 公開日（`YYYY-MM-DD`）。
- `updated`: 更新日（任意）。
- `summary`: 一覧に表示する概要（任意）。
- `tags`: 記事に付けるタグの配列。複数指定でき、タグは記事ごとに自由に追加できます。
- `pinned`: `true` にすると一覧の上部に固定します。
- `published`: `false` にすると非公開になります。省略時は公開扱いです。

カテゴリの固定リストは設けません。タグは Front Matter の `tags` に記載した値から自動的に集約され、一覧画面のタグフィルターに反映されます。

## 本文

本文は通常の Markdown で記述します。長文記事を想定し、見出し（H2/H3）、段落、リスト、引用、リンク、画像、コードブロックなどを利用できます。記事詳細ページでは見出しから目次を自動生成します。HTML は無効です。
